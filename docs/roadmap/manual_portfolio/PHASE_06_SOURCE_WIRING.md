## 2. Тарификация (I-4)

**Формулировка задания содержит две ошибки** (`README.md §1.2`, E-1 и E-2):
функции `_price_for` в проекте нет, а ключи `TIER_COST` — в нижнем регистре.
Действующая функция — `_effective_cost` (`tg_bot.py:316-322`):

```python
def _effective_cost(tier: str, source: str) -> int:
    """Демо-отчёты бесплатны — платится только однозначно определённый ЖИВОЙ источник."""
    return 0 if source == "demo" else TIER_COST[tier]
```

**Правка не требуется.** `source == "manual"` не равен `"demo"`, значит уже сейчас
возвращается полная цена тарифа. Работа фазы — не изменить код, а **закрепить это тестом**,
чтобы будущая правка `_effective_cost` не сделала ручные отчёты бесплатными молча:

```python
assert _effective_cost("deep",     "manual") == TIER_COST["deep"]     == 2
assert _effective_cost("base",     "manual") == TIER_COST["base"]     == 1
assert _effective_cost("scenario", "manual") == TIER_COST["scenario"] == 1
assert _effective_cost("deep",     "demo")   == 0        # I-3 не тронут
```

**Почему `manual` платный.** Стоимость отчёта не зависит от того, откуда взялся список
позиций: LLM-вызовы, SEC EDGAR, загрузка истории и рендер одинаковы. Бесплатен `demo`
не потому, что он шаблонный, а потому что он не несёт пользовательской ценности —
это витрина. Ручной портфель — настоящий, отчёт по нему настоящий.

## 3. Ветка `manual` в `cb_confirm`

`cb_confirm` (`tg_bot.py:1898`) сегодня ветвится на `freedom` / `demo` (2005-2066).
Добавляется третья ветка: вместо похода к брокеру портфель берётся из черновика
(Фаза 5) и собирается через `manual_portfolio` (Фаза 4).

Три места требуют внимания:

| Место | Что делать |
|---|---|
| Гейт fallback-мока (2117-2134) | Ручной DataFrame **никогда** не несёт `_ramp_is_mock`/`_ramp_is_fallback` (`PHASE_04 §2`), поэтому гейт его не трогает. Условие `source != "demo" and _attrs.get("_ramp_is_mock")` остаётся как есть — переписывать не нужно |
| Превью портфеля (2137) | `_format_portfolio_preview(df)` (337) читает `df["Asset_Type"]`, если колонка есть. Ручной фрейм её несёт → превью работает без правок |
| Строка статуса (1992-1998) | Текст «Подключаюсь к Freedom Broker» для `manual` неверен. Своя формулировка: «Собираю ваш портфель…» |

`DataQualityBlocked` (Фаза 3) обрабатывается там же, где `RealPortfolioRequired`, —
путь «отказ без списания» уже существует и проверен (2093-2108). Никакой новой механики.

## 4. Источник в CoVe (снятие К-2)

`data_lineage._tradernet_status` (`data_lineage.py:97-123`) жёстко подписывает источник:

```python
source = "Tradernet (Freedom Broker)",     # строки 104 и 117
```

Для ручного портфеля на Tradernet это по-прежнему правда (цены грузит тот же провайдер),
но после Фазы 9 — уже нет. Функция переименовывается в `_price_source_status`
и берёт подпись из `ProviderResult.source` / `.convention` (Фаза 2):

```
Цены и история активов · Tradernet (Freedom Broker) · split-adjusted · 1825d · ok
Цены и история активов · Stooq · split-adjusted · 1825d · ok
Цены и история активов · Tradernet 11 · Stooq 2 (fallback) · split-adjusted · warn
```

**Число строк CoVe не меняется** (16 после консолидации 2026-07-09) — меняется
содержимое одной. Это важно: `tests/test_phase18_sprint5.py:683-706` и
`tests/test_phase19_block_audit.py:336-345` строят таблицу и проверяют её состав.

Строки DEGRADE из Фазы 3 добавляются **отдельными** записями, а не вливаются в эту.

### 4.1 Бейдж в шапке отчёта — вне объёма (F-6)

Задание требует «бейдж» в Спринте 7. Бейджа источника в слое отчёта **не существует**
вообще: `grep` по `pdf_payload.py` / `premium_payload.py` / `html_renderer.py` даёт
единственное упоминание — комментарий на `pdf_payload.py:840`. Даже демо-портфель
никак не помечен в самом отчёте (планировалось в `ROADMAP_DATA_RESILIENCE.md §2`,
не сделано).

То есть «бейдж» — не доработка, а **новая фича слоя отчёта**, а `pdf_payload.py`
заморожен I-2. Решение (`PHASE_00 §4`): в этой ветке источник показывается **строкой CoVe**,
которая пользователю и так видна. Бейдж — отдельным PR со снятием заморозки; он полезен
и для `demo`, то есть шире этой ветки. Пункт ★ в `README.md §7`.
